# 支付与安全

## 支持的支付方式

- 支付宝
- 微信支付
- 银行卡（借记卡 / 信用卡）
- 平台余额
- 企业对公转账（仅限企业采购订单）

## 分期付款

平台支持花呗分期和信用卡分期。单笔订单实付满 300 元即可选择分期，支持 3 期、6 期、12 期。分期手续费以支付页面展示为准，部分商品支持免息分期。

## 支付失败处理

若支付失败，请检查：

1. 银行卡余额或信用额度是否充足
2. 支付密码是否正确
3. 网络是否稳定
4. 单笔支付限额是否超出

支付失败的订单会保留 30 分钟，超时未支付将自动取消，用户可重新下单。

## 账户安全

- 建议开启「指纹 / 面部 / 短信验证」多重验证。
- 请勿向任何人泄露验证码，客服不会索要您的支付密码。
- 发现账户异常登录，请立即修改密码并联系客服冻结账户。

## 支付异常与重复扣款

如发生重复扣款或支付成功但订单未生成的情况，系统会在 1-3 个工作日内自动原路退回多扣款项。若未自动退回，可联系在线客服人工核实。
