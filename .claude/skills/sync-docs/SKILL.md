# 同步项目文档

代码新增/修改功能后，把变更同步到三处文档，保持文档与代码一致。

## 三处文档及职责

| 文档 | 更新内容 |
| ---- | ---- |
| `docs/01-需求文档.md` | 术语表、功能需求（FR-x）、非功能需求（NFR）、用户故事、验收标准、交付物清单 |
| `docs/02-技术方案.md` | 技术选型、架构图、分层说明、模块设计、LLM 接口、数据模型、FastAPI 接口、评测/测试方案、配置项、已知边界 |
| `CLAUDE.md` | 目录结构、API 接口、核心设计、重要注意事项（坑）、验证状态 |

## 同步要点

1. **新增功能**：需求文档加 FR + 术语；技术方案加对应模块小节；CLAUDE.md 更新目录结构。
2. **新增接口**：技术方案「FastAPI 接口」表 + CLAUDE.md「API 接口」加对应行。
3. **新增配置项**：`config.py` 里新增的 env 变量，同步到技术方案「配置项」表。
4. **新增/删除依赖**：同步到 `requirements.txt` 与 CLAUDE.md 技术栈。
5. **验证状态**：pytest 用例数、评测样本数与满分项，更新到 CLAUDE.md「验证状态」；测试模块列表同步到技术方案「测试方案」。
6. **保持编号连续、术语一致**：FR/NFR/章节编号不跳号；同一概念两份文档用同一术语。

## 操作

直接读取两份 `docs/*.md` 与 `CLAUDE.md`，按上述要点做增量编辑；改动后确认三处文档自洽、无互相矛盾的描述。
