## 测试用例明细

### test_intent.py

| 用例 | 断言 |
| ---- | ---- |
| test_qa_intent | 「请问运费怎么算」「退款多久到账」「发票怎么开」→ qa |

| test_complaint_intent | 「服务太差我要投诉」「举报商家虚假宣传」→ complaint |
